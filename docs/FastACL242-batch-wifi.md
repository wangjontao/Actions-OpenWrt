# FastACL 2.4.2 批量无线更新

在 FastACL 控制台与无线页面底部新增批量无线面板。

- 分频段自定义新增数量；自动读取驱动容量，无法读取时使用每频段 8 个的保守上限（包含已有无线）。单次最多新增 20 个。
- 自定义名称前缀、起始编号、统一密码与隐藏状态；名称总长最多 32 字节，密码为 8～63 个 ASCII 可打印字符。
- 默认直连，或选择已有 PassWall2 节点；建立独立桥、网段、DHCP 和防火墙，并自动加入 FastACL。
- 建立和清除先预览；清除仅处理本功能标记的无线及其关联配置，不清除固件预置 AP 或手动无线。
- 有未提交配置时拒绝操作；应用在后台执行，检查无线和网段是否启动，失败恢复配置。
- 无线重发现保留原有节点、联网模式、DNS 设置和批量归属信息。

要求：已经安装带运行模式控制器的 FastACL 2.4.2、LuCI、PassWall2，使用 nftables 防火墙。不是从零安装器，也未覆盖 23.05 legacy iptables。

更新不自动建立或删除无线。刷新控制台后使用“批量建立无线”面板。

验证：Lua 与 JavaScript 语法；容量/重名/网段冲突/密码/节点/共享网段拒绝删除等测试；Q30 PRO MTWiFi 实机一条隐藏无线建立与清除、原有配置保留、模拟应用失败恢复全套配置校验和；LuCI POST 和 CSRF 校验。其他机型仍需实机测试，已编译固件不会自动包含新功能，可使用更新脚本。

文件更新备份在 /etc/juliang-fastacl/batch-install-*/，其 rollback.sh 恢复更新前的功能文件。无线操作配置备份在 /etc/juliang-fastacl/wifi-backups/。
