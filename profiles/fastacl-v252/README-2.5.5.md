# JuLiangTK FastACL 2.5.5

以 2.5.3 实机功能基线和后续修复为基础，主要功能已实现，继续进行硬件与长稳测试。

- 统一 JuLiang 拼写；页面、UCI 版本与包版本更新到 2.5.5，包发布号 1。
- 节点按导入顺序排列，支持重命名；国内/海外代理出口均可检测，多个检测源不回退直连。
- 国内/海外 DNS 分组，代理设备使用的 DoH 仍绑定节点/前置；UDP DNS 仅直连可用。
- 单 WiFi 多设备分配、设备编号/统计/MAC 备注；多 WiFi 分配、新建面板折叠记忆。
- 订阅改为带编号的列表，展示名称、周期、最近结果与操作，更新按钮为绿色。
- 顶部状态提示吸附，标题绿色配淡黄色描边；FastACL 归入控制中心，UPnP/NPS 归入网络。
- 受保护的重启、60 秒倒计时与取消；居中登录页显示 JuLiang Network Control Center，并隐藏底部版本信息。

内部包名、服务、UCI、API 继续使用 fastacl252，兼容现有配置；保留 root 和受限 admin 帐号，未扩展 admin 的系统重启权限。

分支：codex/fastacl255。固件流程：JuLiangTK-S20L-FastACL255.yml，仍标记 Testing/prerelease。
此次为源码与实机界面版本同步，未自动启动新固件编译；不代表已经完成全部硬件、长稳、IPv6 或升级回归。
